# Security Policy

## Supported Versions

Only the latest release on the `master` branch is actively supported and receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Instead, report it privately by emailing **petromir@gmail.com**.

Please include the following in your report:

- Description of the vulnerability
- Steps to reproduce or a proof-of-concept
- Potential impact

I'll get back to you as soon as I can. If the issue is confirmed, a fix will be prepared and released as soon as possible, and credit will be given to the reporter (unless anonymity is requested).
